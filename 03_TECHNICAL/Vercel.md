# Vercel

## Role

**[EXPERIMENT]** Vercel was explored as an alternative hosting platform.

## The decision preserved

> **Why wasn't everything migrated to Vercel?**
>
> Because changing hosting wouldn't solve the underlying operational problem.

## The lesson

**[LESSON]** Tool changes feel like progress because they are visible and quick. They are not progress when the real constraint lies elsewhere.

Vercel is **not** portrayed in this archive as a replacement that solved the fundamental problem, because it did not.

# Git & GitHub

## What was learned

**[FACT]** Git and GitHub were learned through the project itself:

- version control as the backbone of deployment
- repositories, commits, and pushing as a working habit
- the difference between a **brand account** and a **personal account**

## Why this layer mattered

**[LESSON]** Introducing Git turned deployment from a manual, fragile action into a repeatable one. Everything after this stage depended on it.

## The decision preserved

> **Why preserve GitHub even when retiring the domain?**
>
> Because the intellectual and technical assets have continuing value even when the public infrastructure does not.

**[LESSON]** Domains expire. Repositories do not. Keep the code and the notes; retire the rented layer.

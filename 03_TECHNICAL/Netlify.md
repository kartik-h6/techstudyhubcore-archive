# Netlify

## Role

**[FACT]** Netlify was used for several deployments of the project.

## What it provided

- static hosting
- deployment from the repository
- custom domain and HTTPS handling

## The problem encountered

**[FACT]** At one point there were domain/subdomain association problems with Netlify.

## The lesson

**[LESSON]** Changing hosting providers does not eliminate the underlying responsibility of maintaining the platform.

Hosting was never the problem. The number of areas, pages and obligations was the problem — and those travel with you to any host.

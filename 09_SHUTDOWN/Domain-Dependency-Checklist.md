# Domain Dependency Checklist

Every place the brand domain may be referenced, and the action required before it lapses.

| Where | Action | Status |
|---|---|---|
| GitHub profile — website/blog field | Point at the personal portfolio, or remove | ☐ |
| LinkedIn — website / contact field | Update or remove | ☐ |
| Email signature | Update | ☐ |
| Résumé / CV | Update | ☐ |
| Other bios and profiles | Update | ☐ |
| Personal portfolio (previously on a brand subdomain) | Re-host independently | ☐ |
| DNS records | Export a copy | ☐ |
| Content on the brand areas | Export before expiry | ☐ |
| Brand repositories | Keep — no action required | ☑ |

## The principle

**[LESSON]** A brand URL tends to spread into more places than expected. The checklist exists so nothing is left pointing at a domain that no longer resolves.

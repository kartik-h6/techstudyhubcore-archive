# Glossary

- **TechStudyHubCore** — the education-focused digital ecosystem: gateway, Pharmacy/B.Pharm, SSLC, Digital Setup, portfolio, calculator, and related experiments.
- **TrailCode** — the early prototype and learning artifact (HTML/JavaScript, client-side rendering) that preceded TechStudyHubCore.
- **PMAS** — Pharmacist-led Medication & Adherence Support / Post-Counseling Medication Adherence Support System. The author's current product direction, tied to M.Pharm Pharmacy Practice.
- **PCI** — Pharmacy Council of India. The newer official PCI syllabus is treated as the source of truth for academic content architecture.
- **PYQ** — previous-year question (an exam resource attached to a topic page).
- **SGPA / CGPA** — Semester Grade Point Average / Cumulative Grade Point Average.
- **Subdomain** — a named division of a domain (for example, an area published under the brand domain).
- **Static architecture** — a site served as pre-built files, with no server-side application logic.
- **localStorage** — browser-side storage for client data. Not a security mechanism.
- **Ollama** — a local runtime for running AI models on the machine.
- **Qwen2.5-Coder** — a coding-focused model run locally (7b variant used).
- **Continue.dev** — an editor-integrated AI coding assistant.
- **M.Pharm (Pharmacy Practice)** — the author's postgraduate programme at RIPER, Anantapur.

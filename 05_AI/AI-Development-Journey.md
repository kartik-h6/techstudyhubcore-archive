# AI Development Journey

## How AI entered the workflow

**[FACT]** AI increasingly became part of the engineering workflow. It was used for:

- coding
- debugging
- architecture discussions
- learning unfamiliar technologies
- prompt engineering
- documentation
- comparing technical approaches

## The local setup

- **Ollama**
- **Qwen2.5-Coder:7b**
- **Continue.dev**

alongside hosted tooling (Gemini / Google AI tooling) and cloud coding-model exploration.

## The principle

> **AI-assisted engineering, not blind AI-generated code.**

## The deeper lesson

**[LESSON]** AI can accelerate implementation, but the developer still needs to understand:

- architecture
- security
- data
- permissions
- failure modes
- requirements
- why the system exists

## The honest limitation

**[LESSON]** AI accelerated *building* faster than it accelerated *maintaining*. It made it easier to create more pages, more areas and more experiments — which is precisely how a solo maintenance problem grows.

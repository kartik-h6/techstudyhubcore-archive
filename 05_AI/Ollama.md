# Ollama

## Context

**[FACT]** **Ollama** was used as the local model runtime that made running local models practical.

## Why it mattered

**[LESSON]** Ollama lowered the operational barrier to local AI: instead of treating a model as a remote service, it became something that could be run on the machine and controlled directly.

This was part of a broader principle adopted during the project:

> AI-assisted engineering, not blind AI-generated code.

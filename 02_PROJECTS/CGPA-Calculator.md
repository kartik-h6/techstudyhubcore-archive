# CGPA Calculator

## What it was

**[FACT]** A calculator project existed as an independent utility.

**[EXPERIMENT]** The project later considered changing an SGPA-oriented calculator into a CGPA Calculator and adding percentage calculation.

## Why it is interesting

**[LESSON]** The calculator was the first genuinely *interactive* asset in the ecosystem — not content, but a tool.

Tools tend to be used repeatedly; static pages are typically visited once. That asymmetry matters for maintenance economics.

## The architectural lesson

**[LESSON]** Calculators should be treated as independent utilities rather than forcing every function into one giant website.

Small, focused, reusable — instead of one monolith.

## Status

**[EXPERIMENT]** Utility-level; retired with the public infrastructure.

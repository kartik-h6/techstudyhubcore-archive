# Pharmacy / B.Pharm

## What it was intended to be

**[FACT]** The Pharmacy section was intended to become a structured academic learning platform — the vertical closest to the author's own field.

## The planned hierarchy

```text
Program
→ Semester
→ Subject
→ Unit / Chapter
→ Content Page
→ Resources
```

## The key architectural lesson

**[LESSON]** A PDF should be treated as a *resource*, not as the primary content architecture.

A topic should ideally have a **permanent content URL**, while PDFs, diagrams, videos, previous-year questions and external resources become resources *attached* to that topic.

This was a shift from file-centric content to knowledge architecture. See `03_TECHNICAL/Content-Architecture.md`.

## The second key lesson

**[LESSON]** The newer official **PCI syllabus** should be the source of truth for the academic architecture.

Old TrailCode content should not automatically determine the new curriculum structure.

# UX Lessons

## Learned during the project

- **[LESSON]** Mobile-first matters more than desktop polish for student audiences
- **[LESSON]** Navigation that assumes many areas becomes confusing when those areas are thin
- **[LESSON]** Consistent design across subdomains is expensive; inconsistency is worse
- **[LESSON]** Utility tools earn repeat visits; static pages rarely do

## The core lesson

> Users return for function, not for structure.

The subdomain architecture reflected the builder's mental model more than the user's need. A visitor does not care which subdomain holds a subject; they care whether the answer is easy to find.

## The gateway insight

**[LESSON]** A routing gateway only works if the destinations behind it are strong. Otherwise it advertises more than exists.

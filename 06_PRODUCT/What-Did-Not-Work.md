# What Did Not Work

Recorded deliberately. Failures are the most reusable part of this archive.

**[FACT / LESSON]** The following did not work as intended:

- Scope expanded too far
- Too many independent subdomains and projects for one person
- Maintenance obligations accumulated
- Domain / DNS / hosting complexity increased
- Some experiments remained incomplete
- Team formation was expected but never confirmed
- Some prototypes were not production-secure
- Infrastructure sometimes became the focus instead of the underlying problem
- Building more pages was not necessarily equivalent to creating more value
- Changing hosting providers would not solve the core operational problem
- Keeping the domain alive indefinitely would create recurring cost and attention burden

## The summary

**[LESSON]** The project did not fail at technology. It outgrew its operating model — one person, no confirmed team, and an expanding set of obligations.

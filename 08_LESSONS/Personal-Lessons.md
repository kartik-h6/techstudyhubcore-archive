# Personal Lessons

**[FACT]** This work was done from a **pharmacy background**, not a formal computer-science background. That context shapes every lesson below.

**[LESSON]**

- A non-CS background does not prevent serious technical learning.
- Real projects teach things tutorials cannot.
- Deployment problems teach infrastructure.
- Security mistakes teach architecture.
- Product experiments teach validation.
- AI can accelerate learning when combined with understanding.
- Solo capacity is finite.
- Technical ambition must be balanced against available time.
- Closing an experiment can be a rational engineering decision.

## The transferable value

**[LESSON]** Experience from failed or unfinished experiments is still experience. The skills — infrastructure, security awareness, product thinking, AI-assisted workflow — are permanent, even though the public infrastructure is not.

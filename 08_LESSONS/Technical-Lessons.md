# Technical Lessons

## Skills acquired through the project

**[FACT]** HTML / CSS / JavaScript · Git / GitHub · deployment · DNS · Cloudflare · Netlify · Vercel · subdomains · static architecture · responsive / mobile-first design · WebGL / Three.js concepts · APIs · local AI · AI-assisted coding.

## Engineering principles learned

**[LESSON]**

- frontend ≠ backend
- localStorage ≠ secure authentication
- frontend validation ≠ authorization
- domain ownership is infrastructure
- secrets must stay out of frontend code and Git
- architecture should precede mass content generation
- don't create infrastructure merely because you can
- hosting, domain and DNS are separate layers — changing one does not fix another

## The most valuable single insight

**[LESSON]** The layer model:

```text
Source code → GitHub → Hosting → Domain → DNS → Application
```

Understanding that separation turned infrastructure from magic into a system with discrete parts.
